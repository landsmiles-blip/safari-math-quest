# MEP Primary 3 Science Quest: Data & Interface Contract

## Global Namespace: `window.ScienceQuest`

```javascript
window.ScienceState = {
  playerName: "Junior Explorer",
  currentScreen: "start", // 'start' | 'hub' | 'lab' | 'exam' | 'remediation' | 'certificate'
  currentLabId: null, // 'magnet' | 'friction' | 'thermal' | 'nutrition' | 'lifecycle'
  badges: {
    magnet: false,
    friction: false,
    thermal: false,
    nutrition: false,
    lifecycle: false
  },
  firstPlayCompleted: false, // Locked until all 5 badges are collected on 1st run
  exam: {
    currentQIndex: 0,
    questions: [], // 15 questions generated by ScienceCurriculum
    userAnswers: [], // Array of { qIndex, answer, isCorrect, pointsEarned }
    domainScores: {
      needs: { correct: 0, total: 3, label: "Needs & Food Groups", labId: "nutrition" },
      animals: { correct: 0, total: 3, label: "Animal Diets & Care", labId: "nutrition" },
      cycles: { correct: 0, total: 3, label: "Life Cycles", labId: "lifecycle" },
      thermal: { correct: 0, total: 3, label: "States of Matter & Heat", labId: "thermal" },

    },

    weakestDomain: null // Identified for remediation if score < 12
  }
};
```

## Module Specifications:

### 1. `ScienceCurriculum` (`science_curriculum.js`):
- `generateExam()`: Returns array of 15 questions with progressive difficulty (Levels 1 to 5).
  - Each question object format:
    ```javascript
    {
      id: 1,
      level: 1, // 1 to 5
      domain: 'needs', // 'needs' | 'animals' | 'cycles' | 'thermal' | 'forces'
      type: 'single' | 'scenario', // 'scenario' has sub-parts a, b, c
      title: "Question Title",
      scenarioText: "Optional visual scenario context (e.g. Pip's toy car ramp test)",
      diagramSvg: "<svg ...> or null", // visual apparatus diagram
      subQuestions: [ // 1 item if 'single', 2-3 items if 'scenario'
        {
          part: "a", // or ""
          prompt: "Which surface caused the greatest friction?",
          options: ["Ice Sheet", "Rough Sandpaper", "Smooth Tile", "Glass"],
          correctIndex: 1,
          hint: "Friction is higher on rough, bumpy textures!",
          explanation: "Rough sandpaper grips the wheels and slows the car down quickly."
        }
      ]
    }
    ```
- `evaluateExam(userAnswers)`: Calculates total marks (0-15), domain scores, and identifies `weakestDomain` (and recommended `labId`).

### 2. `InteractiveLabs` (`interactive_labs.js`):
- `mountLab(containerId, labId)`: Renders interactive micro-lab inside container.
  - `magnet`: Bar magnets track + Magnetic sorting tray with horseshoe magnet.
  - `friction`: Pip's adjustable ramp (15/30/45 deg) + 5 surfaces (Ice, Tile, Wood, Carpet, Sandpaper) + Speedometer & Ghost car.
  - `thermal`: Heat/Cool pad slider + Thermometer gauge (-10C to 110C) + 4 substances (Ice, Chocolate, Wax, Raw Egg).
  - `nutrition`: 3 Food pods (Carbs, Protein, Vitamins) + Animal diner (Bunny, Tiger, Bear).
  - `lifecycle`: 4-station circular astrolabe wheel for Butterfly, Frog, Chicken.
- Dispatches `ScienceApp.onLabCompleted(labId)` when the student successfully finishes the experiment challenge to award the lab badge.

### 3. `ScienceAudioUI` (`science_audio_ui.js`):
- Procedural Web Audio API sound synthesizer:
  - `playSound('bubble')`
  - `playSound('magnetClack')`
  - `playSound('repelPulse')`
  - `playSound('carZoom')`
  - `playSound('heatFlame')`
  - `playSound('freezeChime')`
  - `playSound('correct')`
  - `playSound('wrong')`
  - `playSound('fanfare')`
- Speech synthesis:
  - `speakText(text)` using soft female voice synthesis.

### 4. `WallpaperCertificate` (`wallpaper_certificate.js`):
- `renderCertificate(canvas, { studentName, score, domainScores, date })`:
  - 2400x1696 (300 DPI) landscape render.
  - Holographic golden guilloché border, corner rosettes, stardust nebula background.
  - 32-point gold embossed guild seal.
  - 15-star constellation matrix (3 stars for each of the 5 domains).
  - 3D embossed gold student name.
  - Procedural QR security code and examiner signature.
- `downloadWallpaper(canvas, filename)`: Triggers high-res PNG download.
- `printCertificate()`: Native window.print with @media print CSS.
