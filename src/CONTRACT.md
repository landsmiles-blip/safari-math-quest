# Safari Math Quest - Integration Contract

To ensure all concurrent modules integrate seamlessly into the final single-file HTML app, please adhere to these interface contracts.

## 1. Global State Object
The game state is managed globally:
```javascript
window.SafariState = {
    playerName: "",
    mode: "start", // 'start', 'training', 'exam', 'results'
    score: 0,
    currentQuestionIndex: 0,
    missedQuestions: [], // indices of missed questions for near-miss retry
    questions: [] // Array of question objects generated by Math Engine
};
```

## 2. DOM ID Conventions (UI Shell)
- `#app-container`: The main wrapper.
- `#screen-start`, `#screen-training`, `#screen-exam`, `#screen-results`: The main views (toggled via CSS `display: none` or `.hidden` class).
- `#exam-visual-prompt`: `<div>` for the visual question text (e.g., "What is 45,208 in words?").
- `#exam-visual-display`: `<div>` for the big numbers/math problem.
- `#exam-options-container`: `<div>` holding the multiple-choice buttons.
- `#btn-awaken-gold`: The pulsing button on the Silver results screen.
- `#canvas-scratchpad`: The `<canvas>` overlay for drawing.
- `#canvas-certificate`: The `<canvas>` for the generative art.

## 3. Math Engine Interface
The Math Engine should expose a global object:
```javascript
window.MathEngine = {
    generateExam: function() { /* returns array of 15 question objects */ },
    validateAnswer: function(questionObj, selectedAnswer) { /* returns boolean */ }
};
// Question Object Structure:
// { id: 1, type: "place_value", visualPrompt: "...", visualDisplay: "...", audioPrompt: "...", options: ["A", "B", "C", "D"], correctAnswer: "A", category: "Numbers" }
```

## 4. API Interface
The Cognitive API should expose:
```javascript
window.CognitiveAPI = {
    playAudioPrompt: function(text) { /* 0.84 rate, 1.05 pitch, 700ms delay */ },
    playSuccessChime: function() {},
    playErrorChime: function() {},
    initScratchpad: function(canvasId) {}
};
```

## 5. Canvas Art Interface
The Generative Art engine should expose:
```javascript
window.ArtEngine = {
    renderCertificate: function(canvasId, studentName, score, categoryScores) {},
    downloadCertificate: function(canvasId) {}
};
```
